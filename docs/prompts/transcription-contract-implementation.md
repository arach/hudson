# Implement the transcription contract

Work only in this Hudson worktree. Read AGENTS.md and docs/proposals/transcription-adapters.md. This is implementation, not another design exercise.

Allowed edits: root Package.swift (add one library/target/test target only), packages/native/apple/HudsonKit/Sources/HudsonTranscription/, and Tests/HudsonTranscriptionTests/ under the same HudsonKit directory. No existing voice edits, other checkout changes, dependencies, commits, or pushes.

Implement Foundation-only public Sendable Swift types with HudTranscription prefix. One main type per file; public initializers. Codable value types where durable host persistence needs them. Keep provider policy outside the core. Define provider/model descriptors, local versus remote origin, secret-free configuration with opaque credential reference and injected async credential resolver, requests with caller operation/source identity, file URL or explicit PCM format, requested features and optional duration/deadline. Model descriptors describe batch/live and documented limits; unknown remains unknown. Whole-request compatibility returns supported/unsupported/unverified plus typed reasons, supplied by adapters rather than provider switches in core.

Define adapter protocol: descriptor, async models(configuration), compatibility(request,configuration), async readiness(configuration), prepare(configuration), submit(file request,configuration) returning batch operation, open live returning session. Optional modes default to typed unsupported error. Batch operation exposes async event stream including accepted provider ID BEFORE completion plus result and cancellation outcomes. Cancellation distinguishes cancelled from remote outcome unknown; no retries in core. Live protocol uses awaited send(chunk) for backpressure, finish, cancel, events. Implement a reusable actor live-event accumulator/state machine: ordered sequences, session/utterance identity, replace provisional revisions, final utterance distinct from terminal session, exactly one terminal, reject late writes, bounded chunk bytes/monotonic chunk sequence and no silent drop. Missing timestamps/confidence remain optional; results preserve native versus derived annotation provenance, provider/model/version, run/source digest, provider request ID, usage.

Implement registry rejecting duplicate provider IDs and retaining unknown saved configurations without substitution. Async enumerate candidates and evaluate compatibility with adapter methods, no static provider list. Do not silently treat unavailable or unverified as ready.

Implement meaningful Swift Testing tests for serialization of unknown model IDs, duplicate registration, compatibility delegation, absent optional annotations, partial replacement/finalization, cancellation/late events, bounded PCM rejection, exactly one terminal, provider acceptance ID preservation. Fake adapters only in tests. Run swift test --scratch-path "$HOME/Library/Caches/codex-builds/hudson-transcription-baseline" --filter HudsonTranscriptionTests. Do not run other builds concurrently using that cache. Report exact files and actual test results. API refinements allowed within these fixed semantics; report unresolved decisions explicitly.
