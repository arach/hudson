# Vantage Practice Session

This canvas is intentionally manifest-defined. It is a lightweight rehearsal for
agent-driven setup: a host or agent can arrange the work surface without Vantage
needing to know the whole product model ahead of time.

## Shape

- Keep tmux as the durable execution identity.
- Keep source files as path-backed canvas artifacts.
- Keep the plan visible as a first-class document.
- Keep the running diff visible as the review surface.
- Let the manifest own layout, theme, tags, selection, and focus.

## Next Pass

- Promote document artifacts from preview-only cards into editable Hudson text
  document surfaces.
- Add external control actions for opening files and refreshing diffs.
- Keep file reads scoped by host policy before this becomes product-facing.
- Let Scout, Talkie, or another host generate this manifest from project context.
